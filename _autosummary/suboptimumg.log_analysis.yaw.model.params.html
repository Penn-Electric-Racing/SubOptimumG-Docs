suboptimumg.log_analysis.yaw.model.params.build_param_layout(model_configuration, irl_car, overrides={})[source]#

Build the parameter vector for model_configuration, boxed around the car YAML’s dynamics_setup priors.

Ca_f, Ca_r, Izz and the steering offset u_off are always present. The Ca scheduler adds per-axle decay rates alpha_f, alpha_r and a shared exponent p; front relaxation adds L_f. Those come from DEFAULT_EXTENSION_PARAMS unless overridden.

Parameters:

  • model_configuration (ModelConfig) – Decides which optional parameters are added.

  • irl_car (IrlCar) – Source of the chassis priors and their percentage bounds.

  • overrides (dict[ParamName, Param]) – Replacement initial guess, bounds and scale for any parameter in model_configuration, e.g. {"L_f": DEFAULT_EXTENSION_PARAMS["L_f"].model_copy(update={"hi": 2.0})}.

Returns:

The parameter vector for model_configuration.

Return type:

ParamLayout
